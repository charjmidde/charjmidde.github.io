Creating a personal website using Python

In this project, I built a personal blogging website using python and the Django framework. To make it, I first set up a virtual environment, then I made database models for other people visiting the site to comment and for me to post, and lastly, used Django’s built in admin interface to manage the content. The reason I didn't continue with this blog website was because Django requires a live Python server and a database to run, meaning if I wanted it online I would have to pay. Also maintaining a full backend database just to host simple static content was unnecessary overhead. I instead chose github pages to make my website because it offers free hosting that updates automatically whenever I push code from my IDE to my repository, making it the easier choice.
